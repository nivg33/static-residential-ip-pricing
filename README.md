## 静态住宅ip和动态住宅ip差在哪，你该选哪个

静态住宅 IP 是一个在较长周期内不变的住宅网络出口，今天 203.x.x.x，一周后还是同一个地址，更像一条固定宽带。动态住宅 IP 按请求、按时间或按会话自动更换出口，目标网站每次看到的可能来自不同家庭网络。

| 对比项 | 动态住宅 IP | 静态住宅 IP |
| --- | --- | --- |
| IP 是否固定 | 否 | 是 |
| 是否自动切换 | 支持 | 不支持 |
| 长时间稳定连接 | 一般 | 优势明显 |
| 全球地区切换 | 灵活 | 通常固定 |
| 适合批量请求 | 是 | 一般 |
| 成本模式 | 多为按流量计费 | 多为按 IP 或时长计费 |
| 典型应用 | 数据采集、广告验证、市场分析 | 固定办公、长期在线、固定出口 |

两者的差别落在身份连续性上。同一个 IP 用久了，平台会积累出完整的认知：什么时间段活跃、登录频率多高、操作节奏怎么样。店铺日常运营、社媒账号维护、广告账户投放管理依赖这种连续性，频繁换 IP 在风控模型里本身就是可疑信号。动态 IP 的价值在另一头，它让请求分散、彼此难关联，适合采集、比价、批量验证这类不需要固定身份的任务。

有一组常被引用的对照数据：某项目把账号分成静态固定组和动态轮换组跑了一个月，动态组收到的身份验证提示和人工审核通知是静态组的将近 700%。这属于单一项目、未具名平台的经验，样本量也没公开，不能当统计结论用，但方向值得参考。

选型可以压成三个问题：业务是否必须长期维持固定网络身份？IP 变了业务连续性受多大影响？访问频率和并发在什么水平？答案分别是“需要”“影响大”“较高且持续”，选静态；分别是“不需要”“无所谓”“高频但分散”，选动态。

两类混用也常见，前提是边界清楚：店铺运营走静态，竞品调研和采集走动态，别在同一个操作流程里来回切。做账号矩阵要算一笔账，100 个账号只有 20 个静态 IP，等于每个 IP 挂 5 个账号，在平台眼里这就是明确的关联信号，这种情况动态加指纹浏览器更合理。

## 四步验真：怎么确认买到的是真住宅 IP

第一步，通过代理访问 `ipinfo.io/json`，看三个字段。`org` 显示 AS7018 AT&T、AS7922 Comcast 这类服务个人用户的 ISP，通常是住宅；显示 AS14061 DigitalOcean 或 AWS、Azure，就是数据中心。`hosting` 为 true 是强数据中心信号，`type` 为 isp 表示运营商、为 hosting 表示机房。

第二步，用 Scamalytics 查风险分和 `is_datacenter` 字段。作为参照，ZoroCloud US-Astra 的 Scamalytics 评分 6 属低风险，IPQualityScore 评分 65 偏高，测评给的解释是这个 IP 段比较少见、全段被 IPQS 标记。两个分数打架时看具体原因，别只看一个数。

第三步，拿目标平台实测。TikTok、Netflix、ChatGPT 这类平台能不能正常识别地区、会不会弹验证，比任何第三方评分都直接。

第四步，反查 IP 段归属。用免费测试 IP 配合 WHOIS 查 IP 段属于谁，能筛掉不少换皮的服务商。

单一指标都证明不了住宅属性，ASN 归属、地理位置匹配、平台实测三项合起来才能下判断。

除验真之外，还有三个能横向比供应商的实测指标：从池子里随机取 100 个 IP 逐个建连，存活率 95% 以上算合格，低于 90% 用起来会很折磨；连续 1000 次请求算 P95 和 P99，P95 在 3 秒内算及格、2 秒内算良好，P99 经常破 10 秒说明极端承压下不行；用 ipapi、ipinfo 核对宣称城市和实际出口，差得离谱的多半是机房 IP 冒充。

**IP 是否独享。** 静态只描述地址连续性，不描述归属。GetIPProxy 明确写每个 IP 独享、不随请求轮换；SixtyNet 官网没有在住宅套餐页写明独享与否，问一句更稳。

**到期能不能续到同一个 IP。** GetIPProxy 的规则是必须在订单到期前完成续费才能继续用同一个 IP，订单一到期原 IP 不再保留，之后重买可能分配新地址。做长期账号运营，这条比价格重要。

**换 IP 收不收费。** IP 被平台标记后不得不换，有的服务商按次收费，有的按新 IP 剩余价值折算。签约前问清楚，最好写进订单备注。

**并发上限写不写进合同。** 不少“不限流量”套餐在并发连接数上有隐性上限，单线程跑正常，并发一上来就排队或拒绝，通常藏在服务条款小字里。要求对方明确写出并发上限，再用真实负荷压测。

**流量单向还是双向计费。** ZoroCloud US-Astra 的流量是双向计费，上传下载都扣额度，重度使用等于配额减半。SixtyNet 住宅线标的是 5TB 到 40TB，计费方向官网未注明，值得确认。

## FAQ

### 静态住宅 IP 是永久的吗

不是。它在分配期或套餐有效期内保持稳定，到期或按服务商政策仍可能被替换。把它理解成一条长期租用的固定宽带，不是买断。

### 静态就一定独享吗

不一定。静态说的是地址连续性，独享说的是这个 IP 或端点是否只给你的账户用，两件事要分开确认。

### 能保证精确到城市吗

不能。IP 定位是估计值，不同数据库的结果也会不一致。依赖城市级结果之前，用目标平台实测一次实际出口。

### HTTP(S) 还是 SOCKS5

看客户端。HTTP(S) 适合大多数 Web 客户端，SOCKS5 更通用，但要确认客户端的 DNS 行为，避免解析泄漏。

### 有了住宅 IP 就不用指纹浏览器了吗

不够。现代风控还看 UA、Canvas、WebGL、时区、语言、字体、分辨率、鼠标轨迹。代理 IP 加指纹浏览器、独立 Cookie 存储、行为节流，四样齐全才算环境隔离到位。
